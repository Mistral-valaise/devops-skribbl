# DevOps Skribbl 🎨

A fun drawing and guessing game featuring SRE (Site Reliability Engineering) and DevOps terminology! Perfect for team building, learning new concepts, or just having fun with your tech team.

## 🎮 How to Play

1. Open `index.html` in your web browser
2. Choose a difficulty level:
   - **Easy**: Basic DevOps concepts (Docker, Kubernetes, Git, etc.)
   - **Medium**: Intermediate practices (CI/CD, Microservices, GitOps, etc.)
   - **Hard**: Advanced concepts (Distributed Tracing, Service Mesh, etc.)
3. Draw the word shown at the top of the screen
4. Have your teammates guess what you're drawing!
5. Click "Next Word" to get a new term
6. Use "Hide/Show Word" to hide the word from your view while others guess

## 🎨 Drawing Tools

- **Color Palette**: 8 different colors to choose from
- **Brush Size**: Adjustable from 1-20 pixels
- **Clear Canvas**: Start fresh with a blank canvas
- **Touch Support**: Works on tablets and touch-enabled devices

## 📚 Word Categories

The game includes **75 terms** across three difficulty levels:

- **Easy** (25 terms): Basic DevOps tools and concepts
- **Medium** (25 terms): DevOps practices and methodologies
- **Hard** (25 terms): Advanced SRE and architectural patterns

## 🚀 Getting Started

Simply open `index.html` in any modern web browser. No installation or server required!

```bash
# Clone the repository
git clone https://github.com/Mistral-valaise/devops-skribbl.git

# Open in browser
cd devops-skribbl
open index.html  # On macOS
# or
start index.html  # On Windows
# or
xdg-open index.html  # On Linux
```
